# 에이전트 설계 학습 노트

주문 문의를 처리하는 작은 시스템을 예로 들어, 다음 행동을 누가 결정하고 결과를 어떻게 검증할지 연습한다.

1. 폴더를 내려받고 [학습 페이지](index.html)를 브라우저에서 연다. 다섯 패턴의 흐름을 펼쳐 보고 각 질문에 먼저 답해 본다.
2. [실행 루프·컨텍스트·도구 설계](foundations.md)에서 모델과 실행 코드의 책임을 나눈다.
3. [패턴 선택 노트](patterns.md)로 돌아가 입력 조건 하나를 바꾸면 설계가 어떻게 달라지는지 살펴본다.
4. [상태·평가·복구](reliability.md)를 읽고 [응답 유실 실험](experiments/retry.py)을 Python 3으로 실행한다.

[원문과 근거 범위](references.md)에 외부 설계 원칙을 정리했다. 문의 사례와 실험은 이 노트의 학습 예제다. 새 메모에는 선택을 바꾼 조건, 재현 가능한 입력, 관찰한 결과와 남은 질문을 함께 기록한다.
